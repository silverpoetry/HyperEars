# 桌面电量组件

在桌面的小组件列表添加 **HyperEars 电量**。组件可调整大小：普通尺寸采用紧凑排版，
拉宽后采用横向排版。默认自动显示最近连接且已确认的耳机，也可点“选择设备”固定到
一个曾收到状态的地址。固定设备不在线时不会自动改为另一副耳机；较小高度下可从桌面
的组件配置入口更改选择。

电量区域可点按打开该耳机的蓝牙设置；组件本身没有降噪、音量、查找或其他控制按钮。
只显示实际收到的耳机／左耳／右耳／充电盒电量，未知值显示破折号，0% 保留为有效值。
只有整体电量时不会伪造左右耳。系统接管的设备会清除组件中的私有电量，显示“由系统管理”。

组件显示的是**上次记录**，不是后台持续刷新的实时读数。“记录”的时间是电量投影首次
观察或变化的时间；普通状态变化和快照回放不会刷新这个时间。尚无可信记录时间时明确
显示未知。断开和进程重启后保留的数值仍是历史记录，不代表耳机此刻在线。没有定时轮询、
后台保活服务或额外通知权限；添加、重新配置或调整尺寸会请求现有状态快照。

## 实现与验证边界

单一 RemoteViews provider 负责桌面生命周期。独立状态 receiver 默认禁用且没有 intent-filter，
仅在组件存在时启用。Bluetooth 进程通过现有认证广播路径显式发送电量精简投影；高频运动、
EQ 与无关 revision 不进入组件投递。原生准入、producer、物理连接、session、revision 检查
复用既有约束，组件不自行授予准入或打开蓝牙通道。模块应用没有运行时，桌面残留视图也
始终使用“上次记录”表述；应用存活期间会监听 producer 死亡并撤回已验证状态。

本地持久化只有展示数据与每个组件的设备选择，不保存 Binder、session/connection token、
控制请求或完整 EarbudState。移除最后一个组件会禁用状态接收器并清除组件缓存与选择。
AndPods4.3.8 的 provider/helper 仅作为功能与生命周期研究参考，没有复制代码或资源。

单元及 Robolectric 覆盖投影、时间去重、整体电量、陈旧身份、producer 死亡、系统接管清除、
真实 RemoteViews、尺寸、组件删除、认证接收和 BluetoothDeviceSettings 路由。构建／代码验证
不等同于具体桌面启动器的实机排版验收。

当前每个接收进程最多保留 32 个不同设备的身份与展示记录；达到上限后拒绝新地址，避免淘汰仍用于拒绝旧连接／旧会话的身份防护。移除全部组件会清除记录后重新开始；同一地址的重连不占新名额。

本轮定向组件测试已在启用真实 Android 打包资源的 Robolectric 环境通过；紧凑、横向与深色大字体的原生渲染图片已审阅。具体桌面启动器上的添加、缩放、恢复与点击体验仍以实机验收为准，未执行手机操作。
