# ROSE RFCOMM 型号画像

## 来源与身份

本轮型号边界依据 HyperRose 提交 `4e212f79bb1929892e4ac8ae22ed5c2d351e6944`
的 `EarFeelI7Profile.kt` 与 `CeramicsUProfile.kt`，独立整理协议事实。
新增型号尚未在 HyperEars 实机复核。

- `EarFeel i7`、`ROSE EARFEEL i7` 精确匹配 i7，不沿用 i5 的 GATT 候选路径。
- `ROSE Ceramics U` 精确匹配独立 U 画像，不再与 Ceramics Ultra 合并身份。
- `ROSE Ceramics Ultra` 保留原有适配和证据。名称后缀不自动归入新画像。
- 系统已支持的设备继续由系统处理。

## 会话与控制

两个新画像使用 RFCOMM UUID `0cf12d31-fac3-4553-bd80-d6832e7b3931`，复用已有
BudsFeel 校验帧、状态查询、电量与噪声解析。名称和服务只选择候选，合法设备回报
才确认私有能力。初次探测失败保持休眠；重新连接可重新尝试，不添加轮询。

i7 仅接受噪声值 `1..4`：降噪、关闭、通透、抗风噪。超出画像的 `5/6` 回报不确认
噪声能力，也不覆盖之前的合法状态。U 保留六值解析；现有四态原生卡片将 `5/6`
投影为降噪，高级详情提供六种模式的独立选择，保留实际回报的模式值。
会话重置撤销能力证据。

## 型号限定的高级设置

i7 与 BudsFeel MK2 仅开放合法回报确认后的游戏模式。Ceramics U 另支持六态噪声、
四种 EQ、三档降噪深度、两档通透深度、提示音语言和五档音量。字段与范围来自同一
固定提交；Ultra、Furina 和未知家族不继承这些设置。Coral 使用独立会话与字段定义。

控制通过类型化请求沿用已有 `FF sequence 02 type value checksum AA` 帧，随后查询
状态确认，不乐观修改选中值。原生卡片保留噪声项并提供高级入口；只有设置回报时显示
设置入口，不伪造噪声能力。触控前缀和未知字段不递归解码为功能，保留原有 MK2
状态尾部全零填充。缺少可靠回读的增益、触控重映射与查找不在这批控制中开放。

详情页随会话、控制权或宿主视图失效关闭，遵守宿主昼夜配色。所有新增高级控制尚待
实机复核；本轮不安装或修改手机设置。

测试覆盖精确路由、Ultra 身份保留、原生设备排除、后缀边界、i7 模式范围、原生卡片
投影与重置。测试与来源画像均不替代实际设备验证。
